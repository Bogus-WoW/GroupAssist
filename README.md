# GroupAssist

Tank and healer helpers in one: buff bars, regen timer, drinking and aggro call-outs, loose-mob marks, tank focus. Replaces TankAssist and HealAssist.

An addon for **World of Warcraft: Forever** (interface 16001), made for personal use and shared as-is.

## Install

- **WowUp:** Add Addon → Install from URL → paste this repository's URL. Updates come with each new release.
- **Manual:** download `GroupAssist-<version>.zip` from the Releases page and unzip it so the `GroupAssist` folder sits in `_forever_\Interface\AddOns\`.

Type `/reload` in game after updating.
